## 🚀 Featured Projects

### 🛒 [HoneyCart](https://github.com/Anil-G3/HoneyCart-Backend) — Modular E-Commerce Platform

> `Java` `Spring Boot` `Spring Security` `JWT` `Razorpay` `MySQL` `React JS`

[🔗 Backend Repo](https://github.com/Anil-G3/HoneyCart-Backend) · [🔗 Frontend Repo](https://github.com/Anil-G3/HoneyCart-Frontend)

A full-stack e-commerce backend built the right way — not just CRUD, but real auth, real payments, real structure.

| Feature | Details |
|---|---|
| 🔐 Auth | JWT-based role authentication with Spring Security — separate Admin & Customer access flows enforced at filter level |
| 🌐 APIs | Complete RESTful APIs for products, cart, orders, and payments with consistent response structure |
| 💳 Payments | Razorpay integration end-to-end: order creation, payment capture, and webhook-ready architecture |
| 🗃️ Database | Normalised MySQL schema with indexing on frequently queried fields and proper FK constraints |

---

### 🎬 [CineMatch](https://github.com/Anil-G3/CineMatch) — Movie Recommender System

> `Java` `Spring Boot` `JWT` `MySQL` `HTML` `CSS` `JS`

A backend-heavy recommender that actually computes recommendations — not just a list app.

| Feature | Details |
|---|---|
| 🤖 Engine | Content-based recommendation algorithm built from scratch — analyses user rating patterns |
| 🔐 Auth | Spring Security + JWT stateless auth — tokens issued at login, validated on every protected route |
| 🗃️ Schema | Normalised MySQL across Movies, Genres, Users, Ratings, Watchlist with many-to-many junction tables |
| 🔔 Realtime | Live watchlist updates and email notification triggers for user activity events |
